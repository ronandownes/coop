## Lease reporting | How would you prepare a report required by a Lease Agreement?

I would identify the required output and deadline, confirm the source data, work through the report systematically, check important figures and make sure it is ready early enough for review where required.

requirement | source data | deadline | check | review

## Analysis | How do you approach a problem when you do not immediately know the answer?

I break the problem into smaller parts, identify what is known and unknown, make assumptions explicit and test the result. If I am still blocked, I ask a focused question explaining what I have already tried.

break down | assumptions | test | ask intelligently

## Reporting tools | How would you use Excel, Power BI or code?

I would choose the tool around the task. Excel is useful for inspection, reconciliation and quick calculations; Power BI for repeatable reporting and visualisation; code for larger or reproducible analysis. Whatever the tool, I would validate the output before relying on it.

task | tool choice | repeatability | validation

### Explaining the result

I would explain the main idea in plain language first, then add technical detail only where it helps the decision.
